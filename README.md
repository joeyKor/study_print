# 📚 학습지 제작소 (Kids Study Worksheet Generator)

> **유치부(5세)부터 초등학교 저학년까지!**  
> 아이들의 연령과 발달 단계에 맞춰 필요한 학습지를 생성하고, A4 규격에 딱 맞게 바로 출력할 수 있는 **스마트 교육 워크시트 솔루션**입니다.

---

## 🌟 주요 학습 기능

### 1. 🎯 오늘의 일일학습 패키지 (매일 새로운 학습지 자동 생성)
* **초등2 일일학습**:
  * 🏮 **한자 쓰기** (8급 ~ 3급 선택 범위 중 4글자 무작위 추출)
  * 📚 **사자성어 쓰기** (준4급 / 4급 고사성어 1개 + 4선 쓰기 가이드)
  * 📝 **필수 영단어** (Junior 123 ~ 145권 단어장 중 4단어 + 예문 + 4선 노트)
  * 🧠 **두뇌 연산 퀴즈** (빈칸 연산자 채우기 3문제)
* **유치 5세 일일학습**:
  * 🔢 **숫자 따라쓰기** (1~10 기초 / 1~20 심화 바른 숫자 따라쓰기)
  * 🔤 **알파벳 4선 쓰기** (A~Z 대문자, 소문자, 대소문자 혼합 따라쓰기 + 참 잘했어요 도장)
  * ⏰ **시계 보기 & 첫 연산** (정각/30분 시계 읽기 및 시계바늘 그리기, 점모양 직관 덧셈·뺄셈)
  * ✏️ **그림 한글 낱말 쓰기** (아이들에게 친숙한 동물, 과일, 탈것 그림 보고 따라쓰기)

---

### 2. ✍️ 글꼴 & 따라쓰기 맞춤 환경설정 (Settings)
초기화면 및 학습 화면 상단의 **[설정]** 버튼을 통해 아이의 쓰기 수준에 맞는 글꼴과 스타일을 자유롭게 지정할 수 있습니다. (설정 내용은 브라우저 `localStorage`에 자동 보관됩니다.)

* **한글 따라쓰기 글꼴**:
  * ✍️ **나눔바른펜 (추천)**: 연필 손글씨 정석, 획순과 바른글씨 형성에 최적
  * 📖 **교과서 정자체 (고운바탕)**: 초등 국어 교과서 스타일의 품격 있는 정자체
  * 📝 **바른 교재체 (고운돋움)**: 정갈하고 부드러운 학습지 인쇄체
  * 🎈 **개구체**: 유치부 아이들에게 친근한 동글동글 손글씨
  * 🔲 **표준 고딕 (나눔고딕)**: 깔끔한 정석 고딕 활자체
* **영문·숫자 따라쓰기 글꼴**:
  * 🔤 **ABeeZee (추천)**: 초등 쓰기 교육 표준, 소문자 `a`, `g` 단층(1-story) 정석 뼈대
  * ✏️ **Schoolbell**: 미국 초등학교 칠판/유인물 느낌의 연필 손글씨
  * 🎨 **Comic Neue**: 획 굵기가 일정하고 동글동글한 캐주얼 서체
  * 🔲 **Inter**: 모던하고 반듯한 기본 산스
* **따라쓰기 가이드 스타일 모드**:
  * ◽ **연한 회색 실선 (기본)**: 글자 선을 따라 덮어쓰기 가장 편한 모드
  * ⭕ **속 빈 외곽선 (아웃라인)**: 테두리를 따라 쓰거나 선 안쪽을 색칠하며 익히는 모드
  * ░ **패턴 가이드**: 은은한 빗살 질감으로 집중도를 높여주는 모드

---

### 3. 🎨 풍부한 과목별 전문 워크시트
1. **연산 공부**: 덧셈, 뺄셈, 곱셈, 나눗셈, 혼합계산, 분수 기초 (난이도 1~3단계)
2. **한글 단어 쓰기**: 동물, 과일·채소, 음식, 탈것, 생활 사물, 자연 등 테마별 낱말 쓰기장
3. **한글 기초 쓰기**: 기본 자음·모음 낱자, 낱말, 문장 쓰기
4. **빈 쓰기 양식 (공책 연습장)**:
   * 초등 표준 10칸 깍두기 공책 / 8칸 저학년 공책 / 국어 줄공책
   * 영어 4선 쓰기 노트 (넓은 줄 / 표준 줄) / 영어 낱말 칸 쓰기장
   * 漢字(한자) 쓰기장 / 십자 격자장 / 米자 격자장 / 1cm 방안 모눈종이
5. **한자 쓰기**: 8급부터 3급까지 급수별 한자 획순 가이드 및 연습장
6. **그리기 / 색칠**: 창의력·연산 컬러링, 좌우 대칭 모눈 그리기, 4단계 드로잉 교실
7. **기초 선긋기**: 직선, 물결선, 지그재그, 동물 짝 맞추기
8. **필수 영단어 쓰기**: Junior 123권 ~ 145권 (총 3,300여 개 단어 및 예문 수록)
9. **시계 공부**: 아날로그 시계 시침/분침 그리기 및 시각 읽기
10. **구구단 연습**: 2단~9단 순서 외우기, 빈칸 채우기, 셔플 퀴즈
11. **미로 찾기**: 집중력을 길러주는 단계별 미로 길찾기
12. **맞춤 문장 쓰기**: 부모님이나 선생님이 직접 입력한 문장으로 10칸 깍두기 공책 생성
13. **달력 만들기**: 원하는 년·월을 선택하고 일정을 메모할 수 있는 가로형 달력

## 🖨️ 인쇄 최적화 가이드

* **용지 규격**: A4 (210mm × 297mm)
* **인쇄 팁**:
  * 브라우저 인쇄 창 (`Ctrl + P` 또는 상단 **[인쇄하기]** 버튼 클릭)
  * **여백(Margins)**: `없음(None)` 또는 `최소(Minimum)` 권장
  * **배경 그래픽(Background graphics)**: `체크(활성화)` 권장 (4선 노트 및 그리드 표시용)

## 🐳 시놀로지 도커 (Synology Docker / Container Manager) 배포 안내

본 프로젝트는 순수 HTML, CSS, JavaScript로 구현된 **경량 정적 웹 애플리케이션**이므로, 시놀로지 NAS의 도커(Container Manager) 환경에서 Nginx 컨테이너 하나로 손쉽게 구동할 수 있습니다.

### Docker CLI 배포 예시
```bash
docker run -d \
  --name kids-study \
  -p 8080:80 \
  -v /volume1/docker/study:/usr/share/nginx/html:ro \
  --restart always \
  nginx:alpine
```
* 웹 브라우저에서 `http://[시놀로지-IP]:8080` 접속 시 홈 네트워크의 모든 PC, 스마트폰, 아이패드에서 바로 사용하실 수 있습니다.
* 데이터베이스나 별도 백엔드가 필요 없으며, 각 기기별 맞춤 글꼴 설정은 브라우저에 안전하게 보관됩니다.
